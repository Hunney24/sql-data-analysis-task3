# sql-data-analysis-task3# Task 3 - SQL for Data Analysis

## Objective

The objective of this task was to use SQL to extract, filter, and analyze data from an e-commerce database using MySQL.

## Tools Used

- MySQL
- MySQL Workbench

## Dataset

The analysis was performed using an e-commerce database containing customer and order-related data.

Main tables used:

- customers
- orders

## SQL Queries Covered

The following SQL concepts were used:

1. SELECT, WHERE, ORDER BY and LIMIT
2. GROUP BY and COUNT()
3. AVG() function
4. INNER JOIN
5. LEFT JOIN
6. Subquery
7. Creating and using a VIEW
8. Creating an INDEX

## Analysis Performed

Some of the questions explored through SQL were:

- Which customers are above 30 years old?
- How many customers are there from each country?
- What is the average age of customers?
- How can customer and order information be combined?
- Which orders have a value above the average order value?
- How can a view be created for order analysis?

## Key Findings

- The United States had the highest number of customers in the dataset.
- The average customer age was approximately 46.49 years.
- Customer and order information was successfully combined using SQL joins.
- A subquery was used to identify orders above the average order value.
- A view was created to simplify access to order information.

This task provided practical experience in using MySQL for data analysis, including filtering, aggregation, joins, subqueries, views, and indexes.
